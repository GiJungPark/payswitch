# Claude Code 설정

이 디렉터리는 Claude Code의 저장소 단위 실행 제한을 관리한다.

| 경로 | 용도 |
|---|---|
| [settings.json](settings.json) | Git·GitHub·정책 문서 쓰기와 외부 도구 사용 제한 |

Claude Code는 이 디렉터리를 직접 수정하지 않는다. 정책 변경은 Claude 세션 밖에서 사용자가 승인하고 Codex가 적용한다.
